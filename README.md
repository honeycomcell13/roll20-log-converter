# 롤20 로그 편집기

롤20에서 내보낸 마크다운 채팅 로그를 불러와 읽기 좋은 단일 HTML 파일로 변환하는 브라우저 도구입니다. 파일과 편집 내용은 서버로 전송하지 않습니다.

## 기능

- `.md`, `.markdown`, `.txt` 파일 선택·드래그·클립보드 붙여넣기
- 롤20 인장 이미지, 캐릭터명, 대사, GM 지문, 판정표 유지
- 모든 발화에 동일한 배경을 사용하여 GM 제공 파일의 파란 발화 배경 제거
- 로그 사이에 텍스트형 또는 이미지형 핸드아웃 삽입
- 핸드아웃과 로그 항목 이동·삭제
- 인장 이미지를 가능한 경우 HTML 내부에 포함
- 설치 없이 동작하는 단일 HTML 결과물 저장

## GitHub Pages

저장소의 Settings → Pages에서 `Deploy from a branch`, `main`, `/ (root)`를 선택하면 배포할 수 있습니다.
